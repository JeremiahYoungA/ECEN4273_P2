### Custom Object Detection

## Goals

1. Detect typical objects, such as a Cat, Dog, and Person

2. Detect custom objects, including a Dalek and lightsaber

3. Run real-time with a video stream

4. Achieve a mAP@0.5 of 0.85 on an instructor provided test dataset.
